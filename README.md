# Tahani Beji — Web Developer Portfolio

A responsive personal portfolio and CV website built with HTML, CSS, JavaScript, and Owl Carousel.

## Features

- Personal introduction and downloadable CV
- Skills, education, experience, and languages
- Project showcase carousel
- Contact form with client-side validation
- Social links and embedded map
- Responsive, accessible layout

## Run Locally

Open `index.html` directly in a browser, or start a local server:
